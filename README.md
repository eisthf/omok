# 오목 (Omok)

브라우저에서 즐기는 웹 오목 프로그램입니다. 두 가지 방식을 제공합니다.

- **한 대의 컴퓨터에서 두는 방식** (`index.html`): 두 사람이 한 화면에서 번갈아 둡니다.
  서버가 필요 없으므로 파일을 열기만 하면 동작합니다.
- **온라인 대국** (`online.html`): 두 사람이 각자의 컴퓨터에서 접속하여 둡니다.
  착수를 중계하는 서버가 필요합니다.

## 실행 방법

### 한 대의 컴퓨터에서 두는 경우

`index.html` 파일을 브라우저에서 직접 열면 바로 시작할 수 있습니다.

### 온라인 대국을 포함하여 실행하는 경우

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

기본적으로 `http://localhost:3000` 에서 서버가 실행됩니다. 브라우저로 접속한 뒤 온라인 대국
쪽으로 이동하시면 됩니다. 접속 포트는 `PORT` 환경 변수로 바꿀 수 있습니다.

## 온라인 대국 방식

1. 한 사람이 대국방 코드를 입력하고 입장합니다. **먼저 입장한 사람이 검은 돌을 잡습니다.**
2. "초대 주소 복사" 단추로 주소를 복사하여 상대에게 전달합니다.
3. 그 주소로 들어온 두 번째 사람이 흰 돌을 잡고, 곧바로 대국을 시작할 수 있습니다.
4. 세 번째 이후로 접속한 사람은 관전자가 되어 대국을 지켜봅니다. 관전자는 돌을 놓거나 새
   게임을 시작할 수 없습니다.

대국방 코드가 다르면 서로 다른 판에서 진행되므로, 여러 쌍이 동시에 대국할 수 있습니다. 코드를
비워 두면 `MAIN` 방으로 입장합니다.

착수 규칙은 모두 서버가 확인합니다. 따라서 차례를 건너뛰거나 상대의 돌을 대신 놓는 조작은
받아들여지지 않습니다. 접속이 끊기더라도 같은 브라우저로 같은 주소에 다시 들어오면 원래
자리를 되찾아 대국을 이어서 둘 수 있습니다.

무르기는 자신이 마지막으로 놓은 돌에만 적용됩니다. 상대의 돌은 무를 수 없습니다.

## 규칙

- 오목판은 가로세로 15줄로 이루어져 있습니다.
- 검은 돌이 먼저 두고, 그다음에 흰 돌이 두며, 이후로도 두 색이 계속 교대로 착수합니다.
- 가로, 세로, 두 방향의 대각선 가운데 어느 한 방향으로 같은 색 돌을 다섯 개 이상 연속으로
  놓으면 그 색이 승리합니다. 금수(삼삼, 사사, 장목)를 제한하는 렌주룰은 적용하지 않는
  자유 오목 방식입니다.
- 빈 교차점이 남지 않을 때까지 승부가 나지 않으면 무승부로 처리합니다.

## 배포

### GitHub Pages

정적 파일만 배포하는 서비스이므로 **한 대의 컴퓨터에서 두는 방식만 동작합니다.** 온라인 대국은
서버가 필요하여 이용할 수 없습니다. 저장소 설정의 Pages 항목에서 브랜치와 `/ (root)` 폴더를
지정하시면 됩니다.

### 온라인 대국까지 사용하려는 경우

Render, Fly.io, Railway와 같이 Node.js 프로그램을 상주시킬 수 있는 서비스에 배포하십시오.
시작 명령은 `npm start`이고, 접속 포트는 서비스가 지정하는 `PORT` 환경 변수를 따릅니다.
WebSocket 연결을 사용하므로, 해당 서비스에서 WebSocket이 허용되어 있어야 합니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 한 대의 컴퓨터에서 두는 화면입니다. |
| `online.html` | 온라인 대국 화면입니다. |
| `style.css` | 두 화면이 함께 사용하는 배색과 배치입니다. |
| `omok-core.js` | 착수 규칙과 승패 판정을 담은 공용 모듈입니다. 브라우저와 서버가 같은 파일을 사용합니다. |
| `board-view.js` | 오목판을 캔버스에 그리고 클릭 지점을 좌표로 바꿉니다. |
| `game.js` | 한 대의 컴퓨터에서 두는 방식을 제어합니다. |
| `online.js` | 서버와 주고받으며 온라인 대국을 제어합니다. |
| `server.js` | 정적 파일 제공과 WebSocket 중계를 담당합니다. |
