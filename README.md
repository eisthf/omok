# 오목 (Omok)

브라우저에서 두 사람이 번갈아 두는 웹 오목 프로그램입니다. 별도의 빌드 과정이나 외부
라이브러리 없이 HTML, CSS, JavaScript 파일만으로 동작합니다.

## 실행 방법

`index.html` 파일을 브라우저에서 직접 열면 바로 게임을 시작할 수 있습니다. 정적 서버를
사용하고 싶다면 아래 명령을 실행한 뒤 안내되는 주소에 접속하시면 됩니다.

```bash
npx http-server .
```

## 규칙

- 오목판은 가로세로 15줄로 이루어져 있습니다.
- 검은 돌이 먼저 두고, 그다음에 흰 돌이 두며, 이후로도 두 색이 계속 교대로 착수합니다.
- 가로, 세로, 두 방향의 대각선 가운데 어느 한 방향으로 같은 색 돌을 다섯 개 이상 연속으로
  놓으면 그 색이 승리합니다. 금수(삼삼, 사사, 장목)를 제한하는 렌주룰은 적용하지 않는
  자유 오목 방식입니다.
- 빈 교차점이 남지 않을 때까지 승부가 나지 않으면 무승부로 처리합니다.

## 기능

- 교차점을 누르면 현재 차례에 해당하는 색의 돌이 놓입니다.
- 현재 차례와 승패 결과를 화면 상단에 표시합니다.
- 마지막으로 놓인 돌에는 표시가 남고, 승리한 다섯 돌은 선으로 연결하여 보여 줍니다.
- 한 수 무르기 기능으로 직전 착수를 취소할 수 있습니다.
- 새 게임 버튼을 누르면 판을 비우고 검은 돌 차례부터 다시 시작합니다.
- 착수 순서와 좌표를 대국 기록 목록에 남깁니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조를 정의합니다. |
| `style.css` | 화면 배색과 배치를 정의합니다. |
| `game.js` | 착수 처리, 승패 판정, 오목판 그리기를 담당합니다. |
